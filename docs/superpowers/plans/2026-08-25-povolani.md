**Goal:** Oživit registr 67 civilních povolání — dnes se z něj čtou jen výmluvy a `overtimeRisk`, zbytek je mrtvý a klubový dopad chybí úplně.

**Architecture:** Žádná nová infrastruktura ani DB migrace. Povolání se čte z `players.life_context.occupation`. Klubové efekty se agregují do už existujícího vektoru `StaffEffects` jako třetí zdroj vedle vybavení a placených zaměstnanců. - [ ] **Step 3: Rozšiř `AbsenceTiming`**

V `apps/api/src/events/absence.ts` změň typ:

```ts
export type AbsenceTiming = "day_before" | "match_day" | "training" | "any";
```

V těle `generateAbsences` musí filtry na `timing` nový případ zvládnout. Kategorie `personal`, `absurd`, `hangover` a `commute` filtrují podle `e.timing`; pro `"training"` žádná z jejich položek neodpovídá, takže by fallbacky spadly na prázdno. Uprav filtr tak, aby `"training"` bral položky s `timing === "day_before"` nebo bez `timing` — trénink je přes týden, takže sedí den-předem tón, ne zápasové ráno:

```ts
/** Trénink je přes týden — hodí se tón „den předem", ne zápasové ráno. */
const timingMatches = (want: AbsenceTiming, have: AbsenceTiming | undefined): boolean => {
  if (want === "any" || have === undefined) return true;
  if (want === "training") return have === "day_before" || have === "any";
  return have === want;
};
```

Nahraď jím všechna porovnání `timing === "any" || e.timing === timing` na řádcích ~555, ~564, ~578, ~585. Kategorie `professional` filtr nemá — bere `occupation.excuses` přímo, takže funguje rovnou.

`excuseTiming` u profesní kategorie nastav na `timing`, ne natvrdo `"day_before"`, ať výsledek odpovídá tomu, oč se žádalo.

```ts
/**
 * Pracovní úrazy — zranění, která se nestanou na hřišti.
 *
 * Do 2026-08 bylo pole `injuryRisk` v registru povolání mrtvé. Bez něj se hráči
 * zranili výhradně v zápase, takže kádr mezi koly zamrzl. Dřevorubec s motorovkou
 * má reálně jiný profil rizika než účetní u excelu — a hra to teď ví.
 */

import type { Rng } from "../generators/rng";
import type { Occupation } from "../generators/occupations";
import { generateInjury, type InjuryDef } from "../injuries/injury-generator";

/**
 * Denní sazba. Dřevorubec (injuryRisk 0,6) → ~0,65 úrazu za sezónu (270 dní),
 * programátor (0,02) → prakticky nikdy. Vyladěno tak, aby úraz byl událost,
 * ne rutina — hlídá to test na sezónní odhad.
 */
export const WORK_INJURY_DAILY_RATE = 0.004;

const OBECNE_TEXTY = [
  "Ošklivě jsem si to zavřel v práci, {days} dní pauza.",
  "Uklouzl jsem v práci, doktor říká {days} dní klid.",
  "V šichtě jsem se natáhl, {days} dní budu mimo.",
];

export interface WorkInjury {
  injury: InjuryDef;
  days: number;
  smsText: string;
}

/** Jeden denní hod na pracovní úraz. Vrací null, když se nic nestalo. */
export function rollWorkInjury(
  rng: Rng,
  occ: Occupation | undefined,
  age: number,
  injuryProneness: number,
): WorkInjury | null {
  if (!occ) return null;
  if (rng.random() >= occ.injuryRisk * WORK_INJURY_DAILY_RATE) return null;

  const { injury, days } = generateInjury(rng, age, injuryProneness);
  const pool = occ.workInjuryTexts?.length ? occ.workInjuryTexts : OBECNE_TEXTY;
  const smsText = rng.pick(pool).replace("{days}", String(days));
  return { injury, days, smsText };
}
```

```ts
/**
 * Klubové efekty z civilních povolání kádru.
 *
 * Třetí zdroj do vektoru `StaffEffects` — vedle vybavení
 * (`equipment/equipment-generator.ts`) a placených zaměstnanců
 * (`staff/staff-effects.ts`). Vzor a struktura se drží `staff-effects.ts`.
 *
 * Dvě pravidla, bez kterých se to rozbije:
 *  1. Každá role se počítá jen jednou — bere se nejlepší shoda v kádru.
 *     Jinak má tým jedenácti zedníků opravy zadarmo.
 *  2. S placeným zaměstnancem se nesčítá — bere se vyšší z obou (`mergeEffects`).
 *     Najímání musí zůstat výhodné, profese je bonus, ne náhrada.
 */

import { getOccupationByName, type ClubEffect } from "../generators/occupations";
import { emptyStaffEffects, type StaffEffects } from "./staff-effects";

/** Strop síly profesního efektu vůči dobrému placenému zaměstnanci. */
const OCCUPATION_STRENGTH = 0.4;

/** Nejlepší shoda pro každou roli zastoupenou v kádru. */
export function bestFitPerRole(occupations: (string | null)[]): Map<ClubEffect, number> {
  const best = new Map<ClubEffect, number>();
  for (const name of occupations) {
    if (!name) continue;
    const occ = getOccupationByName(name);
    if (!occ?.clubEffect) continue;
    const stavajici = best.get(occ.clubEffect) ?? 0;
    if (occ.effectFit > stavajici) best.set(occ.clubEffect, occ.effectFit);
  }
  return best;
}

export function calculateOccupationEffects(occupations: (string | null)[]): StaffEffects {
  const fx = emptyStaffEffects();
  for (const [role, fit] of bestFitPerRole(occupations)) {
    const s = fit * OCCUPATION_STRENGTH;
    switch (role) {
      case "udrzba":
        fx.repairCostMul = 1 - s * 0.35;
        break;
      case "travnik":
        fx.pitchDegradationReduction = s * 0.35;
        fx.equipDegradationReduction = s * 0.25;
        break;
      case "bufet":
        fx.concessionDemandMul = 1 + s * 0.25;
        fx.concessionSatBonus = s * 2;
        break;
      case "doprava":
        fx.commuteBonus = s * 0.35;
        break;
      case "zdravotnik":
        fx.injuryExtraHealChance = s * 0.20;
        fx.conditionRegenBonus = s * 2;
        break;
      case "hospodar":
        fx.opsCostMul = 1 - s * 0.15;
        fx.sponsorBonusMul = 1 + s * 0.15;
        break;
      case "zved":
        // Scouting není ve vektoru — řeší occupationScoutMultiplier (Task 13).
        break;
    }
  }
  return fx;
}

/** Pole, kde platí „menší je lepší". Ostatní násobitele a bonusy: větší je lepší. */
const MENSI_JE_LEPSI: ReadonlySet<keyof StaffEffects> = new Set(["repairCostMul", "opsCostMul"]);

/**
 * Sloučí placené a profesní efekty. Nesčítá — bere výhodnější z obou.
 * Bez toho by ekonom vedle účetního v kádru sazby vynásobil.
 */
export function mergeEffects(paid: StaffEffects, occupational: StaffEffects): StaffEffects {
  const out = { ...paid };
  for (const key of Object.keys(out) as (keyof StaffEffects)[]) {
    const a = paid[key];
    const b = occupational[key];
    out[key] = MENSI_JE_LEPSI.has(key) ? Math.min(a, b) : Math.max(a, b);
  }
  return out;
}
```

```ts
/** Referenční teplota, při které je teplotní složka neutrální (jarní/podzimní zápas). */
const REFERENCE_TEMP = 15;

/**
 * Násobič poptávky po produktu podle počasí a měsíce.
 *
 * Nahrazuje dřívější `weatherBeerFactor`, který platil plošně pro pivo i limonádu
 * a klobásu ignoroval úplně — takže ve sněhu klesalo pití o 45 %, ale prodej
 * teplého jídla se nehnul.
 */
export function concessionWeatherFactor(key: ProductKey, weather: Weather, month?: number): number {
  const entry = CONCESSION_CATALOG[key];
  if (!entry) return 1;
  const weatherMul = entry.weatherFactors[weather] ?? 1;
  if (month === undefined) return clampFactor(weatherMul);
  const temp = monthTemperature(month);
  const tempMul = 1 + ((temp - REFERENCE_TEMP) / REFERENCE_TEMP) * entry.tempSensitivity;
  return clampFactor(weatherMul * tempMul);
}

/** Ani extrémní kombinace nesmí poptávku vynulovat ani zdvojnásobit. */
function clampFactor(v: number): number {
  return Math.max(0.3, Math.min(1.8, v));
}
```

|---|---|---|

| Prosinec / červenec | hlubší výkyv než dřívějších 46,8 % | **43,8 %** |
| Podíl klobásy na tržbě | výrazný posun léto → zima | **5,4 % → 27,0 %** |
